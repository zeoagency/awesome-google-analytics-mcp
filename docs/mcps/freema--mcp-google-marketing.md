- Source review only; no tools/list, upstream execution or live authenticated requests.
- Registration is unconditional: auth_status plus analytics, Search Console and AdSense tool arrays. OAuth credentials are required at startup; missing stored refresh token permits startup but blocks every tool except auth_status. Token check is local refresh-token presence, not a live validity check.
- Node >=20 and package dependencies required; package bin points to built dist/index.js, generated by tsup.
- CLI auth, auth --status, auth --logout and help are not MCP tools. No Google Ads implementation is registered.
